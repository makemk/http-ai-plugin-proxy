## 🚀 新特性与关键优化 (Key Highlights)

### 1. 网关配置动态热重载 (Gateway Hot-Reload)
* **实现模块**：`src/core/server.js`
* **优化细节**：`loadConfig(force = false)` 引入了强制磁盘重读机制。
* **业务收益**：当 `deployment.local.json` 从旧节点（如 Node 38）切换到新节点（如 Node 107）时，运行中的代理扩展自动侦测并清空旧连接池、热加载新配置，**无需重启 VS Code 或重启代理进程即可秒级生效**。

### 2. Node.js “半关闭” (Half-Closed) 假死连接彻底根治
* **实现模块**：`src/core/warm-pool.js`
* **根因定位**：当远端 VPS、NAT 网关或中间防火墙发送 `FIN` 单向关闭连接时，Node.js 底层套接字的 `socket.writable` 依然会显示为 `true`。原逻辑在提取温热套接字时误取出该僵死连接，导致请求写入后触发 `RST` 并抛出 5 秒超时卡顿。
* **解决手段**：
  - 为每个预热套接字绑定 `socket.once('end')` 及时销毁；
  - 提取套接字时增加 `!sock.readableEnded && sock.readyState === 'open'` 严格双重校验；
  - 确保出池连接 100% 具备健康双向传输能力。

### 3. 高并发温热连接池扩容至 16 Sockets & 飞行中防击穿
* **实现模块**：`src/network/hardware.js` 与 `src/core/warm-pool.js`
* **硬件级弹性扩展**：自动感应 16 核及以上的高性能 CPU（如 Intel Core Ultra 7 265，20 核），将最大预热连接上限从 6 扩展至 **16 个**（基础常驻保活 4 个），完美承载浏览器打开重型 AI 页面时的 15+ 瞬时切片并发。
* **飞行追踪 (In-Flight Tracking)**：引入 `connectingCount` 计数器，并发突发请求时防止多个线程同时触发预热补偿风暴。
* **主动老化轮转**：温热套接字存活周期收敛至 **25 秒**（确保低于运营商 NAT 普遍的 30 秒无流量淘汰规则），并注入 10 秒 TCP Keep-Alive 心跳。

### 4. 本地环回首微秒 `TCP_NODELAY` 注入
* **实现模块**：`src/core/server.js`
* **优化细节**：在 `server.on('connection')` 握手完成的首个微秒立即调用 `socket.setNoDelay(true)`。
* **业务收益**：彻底消除 Nagle 算法的累积缓冲延迟，本地环回交互耗时压缩至亚毫秒级。

### 5. CLI 命令行冲突自动转为“实时监控看板模式”
* **实现模块**：`cli.js`
* **优化细节**：启动前向 `http://127.0.0.1:18889/health` 发起探针检测。
* **业务收益**：若检测到 VS Code 已经自动拉起了主代理实例，终端不会抛出 `EADDRINUSE` 报错退出，而是自动转入无侵入式的“实时监控看板”，实时输出运行时间、硬件规格、预热池就绪数（如 4/16 Ready Sockets）与连通性。

### 6. 双节点与新型 AI 网关全生态兼容
* **兼容架构**：
  - 完美适配 Node 107（`107.174.199.230:443`）：支持 GOST v3 合规透明 CONNECT 隧道、Sing-box Egress 策略分流与 WARP 动态出口；
  - 完美适配 Node 38（`38.207.167.51:443`）：支持特权 TCP 443 + Let's Encrypt 权威 IP 证书。
* **实测指标**：在预热连接池加持下，Google Cloud Code API 与 OpenAI API 隧道建连耗时稳定在 **`~180 ms`**（跨洋海底光缆单次物理 RTT 极限）。
